# 👨‍💻 Desarrollador de Software Independiente | Arquitectura Full-Stack & Orquestación IA

Desarrollador de software basado en Caracas, Venezuela, especializado en la creación de aplicaciones escalables, orquestación de agentes de inteligencia artificial y diseño de interfaces de alto rendimiento. Actualmente ejecutando un roadmap técnico intensivo orientado al dominio avanzado de arquitecturas modernas.

## 🛠 Stack Tecnológico y Enfoque

| Dominio | Tecnologías y Conceptos |
| :--- | :--- |
| **Frontend** | React, Next.js, Tailwind CSS |
| **Backend & Datos** | NestJS, Prisma, PostgreSQL |
| **Inteligencia Artificial** | Orquestación Multi-Agente (OMA), Model Context Protocol (MCP), Inferencia LLM Local |
| **Filosofía de Diseño UI** | Glass Circuitry, Neobrutalismo, Skeletal UI |

## 🚀 Proyectos Destacados

* **Eros OMA (Orquestador Multi-Agente):** Ecosistema de IA diseñado para la automatización compleja. Compuesto por un "cerebro" central (módulos Planner/Executor), un dashboard web para telemetría y una extensión nativa para VS Code.
* **Rotator Mobile:** Aplicación móvil enfocada en la eficiencia del usuario. (Fase actual: v21.2.0).
* **Bolívar VS Dólar:** Herramienta financiera de monitoreo en tiempo real de tasas de cambio (BCV), desarrollada con un enfoque estricto en la precisión de datos y la experiencia de usuario.

## ⚙️ Objetivos y Operaciones Actuales

* **Dominio Tecnológico:** Ejecución de un plan de 12 meses para la consolidación de 21 tecnologías clave en el desarrollo moderno.
* **Infraestructura Local:** Optimización de configuraciones de hardware (priorización de VRAM y ancho de banda de memoria) para la ejecución e inferencia de modelos de lenguaje (LLMs) en entornos locales sin dependencia de APIs externas.
